# 📦 Project Dumper (GUI)

**Project Dumper** — утилита для упаковки всего кода проекта в единый текстовый файл. Создана специально для быстрой передачи контекста.


## 🚀 Возможности

* **Работает на стандартном Python**.
* Автоматически **пропускает бинарные файлы, картинки и системные папки** (`.git`, `__pycache__`, `venv`).
* **Умеет читать и применять** правила из вашего `.gitignore`.
* **Наглядное ASCII-дерево** файлов.
* **Настройка лимита размера файлов**. 

## ⚙️ Как использовать

1.  Скачайте файл `dump_project.py` в папку вашего проекта.
2.  Запустите его:
    ```bash
    python dump_project.py
    ```
3. Нажмите **"Анализ структуры"**, при необходимости исключите лишние файлы (пробел или клик).
4. Нажмите **"Сделать дамп"**. Готовый файл появится рядом со скриптом.
* Также можно компилировать в `.exe` файл для удобства.
